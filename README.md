# FLAT Project - Digit to Word & Binary Complement
A **Formal Languages and Automata Theory (FLAT)** project demonstrating two operations:  
1. Converting digits (0–9) into words.  
2. Finding the binary complement of a binary number.  

## Project Description

This project is designed to illustrate simple applications of automata and string processing.  
- The **Digit to Word** module takes a digit as input and outputs its word representation (e.g., 7 → Seven).  
- The **Binary Complement** module takes a binary number as input and generates its 1’s complement (e.g., 10101 → 01010).  

## Quick Start
- Run the project in your preferred programming environment.  
- Provide an input digit (0–9) to see its word form.  
- Provide a binary number to view its 1’s complement.  

## Example Usage
- Input: `7` → Output: `Seven`  
- Input: `10101` → Output: `01010`
